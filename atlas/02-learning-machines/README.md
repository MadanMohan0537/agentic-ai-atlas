# Phase 02: Learning Machines

Days 11–20. Train classical models on a tabular rental problem you can explain, and refuse any score that does not beat a boring baseline.

| Day | Level | Project | Summary |
| --- | --- | --- | --- |
| 11 | Beginner | [Baselines that Humiliate Models](day-11-humbling-baselines/README.md) | Score a majority-class rule and a mean predictor before any learned model is allowed to look good. |
| 12 | Beginner | [A Linear Model You Can Read](day-12-readable-linear/README.md) | Fit a logistic model with gradient descent, standardize inputs, and plot reliability in five bins. |
| 13 | Beginner | [A Tree You Can Draw](day-13-a-tree-you-can-draw/README.md) | Grow a shallow decision tree, draw it, and show the overfit when you let it memorize leaves. |
| 14 | Beginner | [Boosted Trees and a Local Reason](day-14-boosted-tables/README.md) | Fit a small gradient-boosted stumps model and explain one prediction by occluding a single feature. |
| 15 | Beginner | [Precision Where It Matters](day-15-precision-at-the-point/README.md) | Rank predictions and read precision and recall at the alert rate operations can actually handle. |
| 16 | Intermediate | [Clusters with Names](day-16-clusters-with-names/README.md) | Cluster docks from usage features and name each cluster from examples, or refuse to name it. |
| 17 | Intermediate | [A Ranker from Pairs](day-17-pairs-ranker/README.md) | Learn to order docks for a rider from pairwise preferences, and evaluate with a rank metric. |
| 18 | Intermediate | [Locked Training Runs](day-18-locked-training-runs/README.md) | Make a training run reproducible: seed, data hash, config file, and a model card stub. |
| 19 | Intermediate | [Slice the Errors](day-19-slice-the-errors/README.md) | Break test error down by a feature you did not train on as a target, and write what you would do next. |
| 20 | Intermediate | [A Threshold from a Payoff Table](day-20-payoff-thresholds/README.md) | Choose a classification threshold from costs you write down, then show how a different cost flips it. |
